# Evidências Newman

Os arquivos PNG desta pasta são capturas de relatórios construídos com os dados reais de requisição e resposta obtidos pelo Newman e renderizados no Edge headless. Eles não representam a interface do Postman ou do Newman.

O Postman Desktop não pôde ser baixado neste ambiente, e o Postman Web exigiu autenticação que não foi concluída. As capturas foram geradas com `npm run evidencias`, a partir das respostas recebidas da API; consulte a coleção em `postman/api-pedidos.postman_collection.json` e o script em `scripts/gerar-evidencias.js`.
